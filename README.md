Необходимо создать список точек. От заданной точки добавить в cgbcjr близлежайшие точки (то есть: сверху, снизу, справа, слева), проверяя, чтобы они не выходили за границы. Закрасить заданную точку и перейти к точке следующей по списку. Если она такого же символа как заданная, также добавить близлежайшие к ней точки в список и закрасить точку. Если точка не такого же символа, просто переходить к следующей. Продолжать алгоритм, пока в списке будет необходимый символ.
